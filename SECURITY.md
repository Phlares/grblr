# Security policy

## Supported versions

Only the latest release tag gets fixes.

## Report a vulnerability

Use "Report a vulnerability" on the Security tab of this repository. The report
stays private until a fix is out. Do not open a public issue for a security
problem.

Include what is affected, the steps to reproduce, and the impact as you see it.
I reply when I can; this is a free-time project, so it may take a few days.

## Content removal

If you find content in this project that uses your voice or your work without
permission, report it the same way with "Removal" in the title. I remove it.
